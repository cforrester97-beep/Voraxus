VORAXUS - installable app (flat version, easy to upload from a phone)
=====================================================================

Upload ALL of these files to the same place. There are no folders.

  index.html            the game
  manifest.webmanifest  app name, icon, colours
  sw.js                 offline support
  icon-*.png            home-screen icons

To update the game later: replace index.html and re-upload.
(Only if you change the icons, also bump CACHE_VERSION at the top of sw.js.)
